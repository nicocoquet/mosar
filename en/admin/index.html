    Updating Mosar data

    Authorized users can update the journal survey here. The workbook is checked and sanitized before any publication.

    The interface will become available once the administration service is configured.
    01 · Sign in

    Restricted access

    Sign in with an authorized GitHub account to upload a new workbook.

    02 · File

    Upload the survey

    Select an Excel file (.xlsx), up to 15 MB. Nothing is published at this stage.

    03 · Review

    Validation report

    Only the sanitized workbook will be saved to GitHub. Review the report before confirming.
