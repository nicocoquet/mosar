# Illustrations des revues

Les illustrations des cartes de l’explorateur sont nommées avec l’identifiant numérique de la revue dans Mir@bel.

Convention :

- `{ID-MIRABEL}.jpg` — illustration spécifique d’une revue ;
- `default.jpg` — illustration générique utilisée automatiquement en l’absence d’image spécifique.

Format canonique : JPEG sRGB, **900 × 300 px** (ratio 3:1), poids cible 80–180 Ko et maximum conseillé ~250 Ko.

Exemple : `853.jpg` pour *Gallia. Archéologie des Gaules*.
